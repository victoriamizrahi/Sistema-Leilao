# Sistema de Leilão

## Sobre o projeto
Sistema informatizado para uma casa de leilões, desenvolvido para apoiar as rotinas da empresa, como o cadastro e o controle das
operações de leilão. Este repositório guarda o código-fonte e o histórico de versões do projeto.

## Tecnologias utilizadas
- Java
- MySQL
- Apache NetBeans
- MySQL Workbench
- Git e GitHub
